Entry for the make.fun bounty "Make the AI Judge Feel Proud: A Family Scene": a Python program that writes one short family scene — a mum who still cuts the crusts off her forty-one-year-old's sandwiches, and the son who eats those crusts in the car so she never has to know he grew up — to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
